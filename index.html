KẾT NỐI CỤC BỘ QUA CÁP USB (COM PORT)

⚡ Chế độ 1: Kết nối trực tiếp USB (Web Serial API — Khuyên dùng tại máy)

Cắm cáp USB từ mạch ESP32-S3 vào máy tính (mặc định 115200 baud) để điều khiển và đọc log trực tiếp không cần mạng.

Hỗ trợ Chrome, Edge, Cốc Cốc trên PC (qua GitHub Pages hoặc Mo_Giao_Dien_Web.bat).

⚠️ Trình duyệt chặn cổng USB trực tiếp khi mở bằng file://
👉 Cách 1 (Online): Mở trực tiếp qua link GitHub Pages https://dat09tn.github.io/shower-test-control/.
👉 Cách 2 (Localhost): Nhấp đúp chạy file Mo_Giao_Dien_Web.bat trong thư mục dự án.
👉 Cách 3 (Python Bridge): Chạy run_serial_bridge.bat rồi mở mục Chế độ 2 bên dưới.
🛠️ Dự phòng: Kết nối qua Cầu nối Python WebSocket (run_serial_bridge.bat — ws://127.0.0.1:8765)
WS: chưa kết nối COM: chưa kết nối
